# PvZ Portable Mod — Original Brutal Framework

Mod original pentru PvZ Portable, cu:
- 60+ funcții în mod menu
- 48+ zombie/variante originale
- abilități custom pentru plante
- integrare modulară în engine
- build Android prin GitHub Actions
- package name: com.pvz.bmexhard

## Build
```bash
cmake -S . -B build
cmake --build build
```
